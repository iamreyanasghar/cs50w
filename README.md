# CS50W — Solutions

My solutions to the problem sets for [CS50's Introduction to Web Programming with Python and JavaScript](https://cs50.harvard.edu/web/) (CS50W).

> **Note:** These are my own solutions, shared for reference and learning. If you're currently taking CS50W, please follow the course's [academic honesty policy](https://cs50.harvard.edu/web/2020/honesty/) and attempt the problem sets yourself first.

<br>

## Projects

| Project | Description | Key Technologies |
|---------|-------------|------------------|
| [`search`](./search) | A Google Search clone with pages for regular search, image search, and advanced search. | HTML, CSS |
| [`wiki`](./wiki) | An encyclopedia built with Django where entries can be created, edited, and searched using Markdown. | Django, Markdown |
| [`mail`](./mail) | A single-page email client with inbox, sent, archived views and dynamic compose/reply/archive actions. | Django, JavaScript, REST |
| [`commerce`](./commerce) | An eBay-like auction site with listings, bids, comments, watchlists, and categories. | Django, SQLite |
| [`network`](./network) | A Twitter-like social network with posting, following, liking, and editing posts. | Django, JavaScript |

<br>

## Tech Stack

- **Python / Django** — backend, models, views, templates
- **JavaScript (vanilla)** — dynamic front-end behavior (fetch API, DOM manipulation)
- **HTML / CSS / Bootstrap** — layout and styling
- **SQLite** — default Django database
- **Git** — version control
