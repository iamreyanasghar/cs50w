SUMMARY OF ALL PARAMETERS:
    - q     : main query (text search & image search)
    - btnI  : "I'm Feeling Lucky" (instant redirect)
    - tbm   : search type (isch = images)
    - as_q  : all these words (AND operator)
    - as_epq: exact phrase (quoted phrase)
    - as_oq : any of these words (OR operator)
    - as_eq : none of these words (exclusion, -term)
